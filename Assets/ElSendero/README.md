# El Sendero

Lo propio del juego. Usa los kits de `Assets/Kits`; ningún kit usa nada de aquí.

- `Content/`: jefes, hechizos, personajes, capítulos, scripts de un solo uso.
- `Data/`: assets del juego (grafos de capítulo, perfiles, tablas).
- `Connections/<Kit>/`: enchufes, es decir, las implementaciones del juego de las interfaces de cada kit.

Reglas completas: CLAUDE.md, regla 8.9, y TDD.md § 31.
